Basic git setup
git config --global user.name "your name"
git config --global user.email "your@email.com"
git config --list


Repository setup
git init - Initialize a repo (new project)
git clone <repo-url> -- Clone an existing repo from GitHub

Check status & History
git status                # Check file status
git log                   # Full commit history
git log --oneline         # Short history
git diff                  # See change

Staging and Committing
git add file.txt                      # Stage one file
git add .                             #stage all files
git commit -m "Add a message"         #Commit changes

Undo Changes 
git restore file.txt          # Discard changes
git restore --staged file.txt # Unstage file
git reset HEAD~1              # Undo last commit
git revert <commit-id>        # Undo commit safely

Branching
git branch                 # List branches
git branch new-branch      # Create branch
git checkout new-branch    # Switch branch
git checkout -b new-branch # Create + switch
git merge branch-name      # Merge branch

Modern Alternative 
git switch branch-name
git switch -c new-branch

Remote Repositories
git remote -v                 # View remotes
git remote add origin <url>   # Add remote

Push and Pull
git push origin main         # Push code
git pull origin main         # Fetch + merge
git fetch                    # Only fetch changes

Stashing temporary save
git stash            # Save changes
git stash list       # View stashes
git stash apply      # Apply stash
git stash pop        # Apply + remove

Tags (for Releases)
git tag              # List tags
git tag v1.0         # Create tag
git push origin v1.0 # Push tag

Useful DevOps Commands
git clone --depth 1 <repo>   # Shallow clone (faster)
git fetch --all              # Fetch all branches
git branch -a                # List all branches (local + remote)
git clean -fd                # Remove untracked files

Pro Tips
Use .gitignore to avoid unwanted files (like .DS_Store, logs)
Commit often with meaningful messages
Always pull before pushing to avoid conflicts
Use branches for features and bug fixes.
